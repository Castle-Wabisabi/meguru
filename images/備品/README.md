# 備品ギャラリー 更新方法

このフォルダの写真は、巡 HP の「DETAILS — 細部に、宿る。」セクションに表示されます。

> **表示は最大16枚まで**（4列×4行）。17枚目以降は自動的に非表示になります。
> 新しい写真を追加したい時は、古い写真を1枚削除してから追加してください。

## 写真を追加する手順（3ステップ）

### ① 写真をこのフォルダに追加
- GitHub の Web 画面で `images/備品/` フォルダを開く
- 「Add file → Upload files」から写真をドラッグ＆ドロップ
- ファイル名は半角英数字推奨（例：`amenity-01.jpg`、`IMG_1234.jpg`）

### ② `index.html` を編集
ファイル内で `details__grid` を検索し、下記の場所に1行追加：

```html
<div class="details__grid">
  <!-- 追加：このコメントの直下に <img> 行を追加してください。 -->
  <img src="images/備品/IMG_0773.jpg" alt="">
  <img src="images/備品/IMG_0774.jpg" alt="">
  <img src="images/備品/新しいファイル名.jpg" alt="商品説明">  ← この行を追加
</div>
```

### ③ コミット → 自動公開
- GitHub の編集画面右下「Commit changes」をクリック
- 数分後、`https://castle-wabisabi.github.io/meguru/` に反映

## 写真を削除する手順

1. `index.html` から該当の `<img>` 行を削除
2. このフォルダから写真ファイルを削除（任意・ストレージ節約のため）

## 推奨される写真

| 種類 | 例 |
|---|---|
| 茶器・カップ・グラス | 昭和の花柄カップ、湯呑み、グラス |
| 行灯・照明 | 和室の行灯、浴室の丸窓ライト |
| 看板・サイン | 「お手洗所」「清潔整頓」レトロ看板、たばこ・郵便看板 |
| ちゃぶ台・座布団 | 和室のちゃぶ台、座布団 |
| 装飾小物 | 古壺、石灯籠、植物、書 |
| 設備の細部 | 蛇口、ドアノブ、襖の引手、畳の縁 |

## 推奨される撮影方法

- **正方形クロップ可能な構図**（サムネイルは1:1）
- **明るい場所で撮影**（影が強すぎないように）
- **接写・クローズアップ**を多めに（細部の質感が伝わる）
- ファイルサイズは 500KB〜2MB 程度に圧縮（画質と読み込み速度のバランス）

## 注意

- ファイル名に **スペース・特殊文字を含めない**（URL でエラーになる）
- 写真の **著作権・撮影許可** に注意（人物が写る場合は許諾を得る）
- 不要な写真はフォルダから削除すると、Git リポジトリのサイズを節約できる
